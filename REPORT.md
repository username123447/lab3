                                                Отчёт по экспериментам с моделями машинного обучения

    1. Данные и подготовка

В работе использовались два набора данных: Student_Performance.csv для задачи линейной регрессии и german.csv для задачи бинарной классификации.

Для линейной регрессии целевой переменной являлся Performance Index. Признак Extracurricular Activities был преобразован в числовой формат: Yes — 1, No — 0.

Для бинарной классификации целевой переменной являлся Creditability. Остальные столбцы использовались в качестве признаков.

Данные разделялись на обучающую и тестовую выборки в соотношении 80/20 с использованием random_state=42.

Для масштабирования признаков применялся StandardScaler. Масштабирование обучающей выборки выполнялось отдельно от тестовой, чтобы избежать утечки данных.

    2. Гипотезы и эксперименты

В работе исследовалась возможность реализации моделей машинного обучения с использованием собственного градиентного спуска.

Для линейной регрессии была реализована собственная модель, обучаемая методом градиентного спуска с минимизацией среднеквадратичной ошибки (MSE).

Для бинарной классификации была реализована собственная логистическая регрессия с использованием сигмоидальной функции и бинарной кросс-энтропии.

Также проводилось сравнение логистической регрессии с двумя классическими алгоритмами машинного обучения: деревом решений (DecisionTreeClassifier) и методом ближайших соседей (KNeighborsClassifier).

Все три классификатора обучались и проверялись на одном и том же разбиении данных.

В качестве гипотезы предполагалось, что логистическая регрессия покажет более высокое качество классификации по сравнению с деревом решений и методом ближайших соседей.

    3. Метрики

Для оценки качества классификации использовались ROC-AUC, Accuracy, Precision, Recall и F1-score.

Собственная логистическая регрессия показала следующие результаты:

ROC-AUC: 0.7919588592800374

Accuracy: 0.755

Precision: 0.7834394904458599

Recall: 0.8913043478260869

F1-score: 0.8338983050847457

Дерево решений показало следующие результаты:

Accuracy: 0.730.

Precision: 0.8387096774193549

Recall: 0.7536231884057971

F1-score: 0.7938931297709924

Метод K ближайших соседей показал следующие результаты:

ROC-AUC: 0.7483052828424497

Accuracy: 0.730.

Precision: 0.78000.

Recall: 0.8478260869565217

F1-score: 0.8125

    4. Выводы

По результатам сравнения классификаторов собственная логистическая регрессия показала наилучшие значения ROC-AUC, Accuracy и F1-score.

Дерево решений показало наиболее высокую Precision, но уступило логистической регрессии по остальным основным метрикам.

Метод K ближайших соседей показал промежуточные результаты.

Таким образом, в проведённом эксперименте логистическая регрессия оказалась наиболее эффективной моделью среди трёх рассмотренных алгоритмов.

    5. Воспроизводимость

Для воспроизведения экспериментов необходимы Python и библиотеки NumPy, Pandas и scikit-learn.

Для разбиения данных использовался random_state=42. Для обучения собственных моделей применялся градиентный спуск.

Параметры обучения: learning_rate = 0.1, epochs = 1000.
